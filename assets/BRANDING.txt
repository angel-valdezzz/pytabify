# Pytabify identity

Version 1: rounded geometry, retaining the project's palette.

- `logo.svg`: transparent symbol, used in navigation and portable reports.
- `favicon.svg`: compact symbol on a white tile for light/dark browser tabs.
- `logo-wordmark.svg` / `logo-wordmark-dark.svg`: outlined lettering, no font download required.

Primary #08745F, secondary #145885, accent #66E1B3.

The wordmark lettering uses DejaVu Sans Bold (Bitstream Vera/DejaVu license; see FONT-LICENSE.txt).

Dark wordmarks use lighter shades of the same hues for contrast.
